Орнату

Adapto OS серверіңізге бір пакеттен орнатылады. Орнату үшін интернет қажет емес: пакетке барлық қажетті бағдарлама, соның ішінде Docker де кіреді.

Әр ұйымға орнату пакетін, лицензияны және бастапқы кодқа қол жеткізу мүмкіндігін береміз. Жаңартуларды да тікелей бізден аласыз. Пакетті сұрату: info@altyncore.kz.

Серверге қойылатын талаптар

Ең төменгі талаптар100 және одан көп пайдаланушы үшін
Процессор2 ядро x86_644 ядро
Жад4 ГБ8 ГБ
Диск30 ГБ50 ГБ-тан бастап, тіркелген файлдардың көлеміне байланысты

Операциялық жүйе: iptables немесе nftables бар Linux x86_64, мысалы Debian 12–13 немесе Ubuntu 22.04 және одан кейінгі нұсқалар. Docker орнатылған болса, Compose модулі бар 24 немесе одан кейінгі нұсқасы қажет. Жүктеме болмаған кезде Adapto OS шамамен 0,5 ГБ жадты және дискіде шамамен 4 ГБ орынды пайдаланады.

Орнату

  1. Пакетті мұрағаттан шығарып, орнатуды іске қосыңыз

    tar -xf box-package-<нұсқа>.tar
cd box-package-<нұсқа>
sudo ./install.sh

    Орнату бағдарламасы кездейсоқ құпиясөздері бар .env баптау файлын жасап, әкімшінің құпиясөзін экранға шығарады. Таза серверге орнату шамамен екі минутқа созылады.

  2. Сервердің мекенжайын көрсетіңіз

    .env файлында мына мәндерді көрсетіңіз: BOX_HOST — қызметкерлер браузерге енгізетін атау; BOX_PORT — порт; BOX_URL — хаттардағы сілтемелерге арналған толық мекенжай. Содан кейін sudo ./install.sh пәрменін қайта орындаңыз. Скрипт деректерді өшірмей, баптауларды қолданады.

  3. Жүйеге кіріп, қызметкерлерді қосыңыз

    Жүйеге әкімші ретінде кіріңіз. Қызметкерлердің есептік жазбаларын жасап, рөлдерін тағайындаңыз немесе AD/LDAP арқылы кіруді баптаңыз.

  4. Орнатуды тексеріңіз

    sudo ./check.sh

    Скрипт жүйе қызметтерін, дискідегі орынды, соңғы түнгі көшірмені, тапсырмаларды жоспарлаушыны және кіру бетін тексереді. Ақау анықталса, хабарлама көрсетеді. Тексеру нәтижесін сұрағыңызбен бірге бізге жібере аласыз.

Қызмет көрсету

Жаңарту

Жаңа нұсқаны тоқсанына бір рет шығарамыз, соңғы екі нұсқаға қолдау көрсетеміз. Жаңарту үшін жаңа пакетті және sudo ./update.sh пәрменін пайдаланыңыз. Скрипт жаңарту алдында резервтік көшірме жасайды. Жаңартуларды орнату міндетті емес.

Резервтік көшірмелер

Жүйе әр түні дерекқор мен тіркелген файлдардың көшірмесін жасап, соңғы 7 көшірмені сақтайды. Көшірмелер сол дискіде қалады. backup.sh скрипті оларды желілік қалтаға (NFS немесе SMB) да сақтайды. Онда соңғы 14 көшірме сақталады.

Қалпына келтіру
sudo ./restore.sh backups/<күні>

Түнгі көшірмені де пайдалануға болады. Сервер істен шықса, деректерді басқа серверде қалпына келтіре аласыз.

AD/LDAP арқылы кіру

Қызметкерлер домендік есептік жазбасы арқылы кіреді. Жүйе рөлдерді домендік топтарға сәйкес тағайындайды. Бұл мүмкіндік OpenLDAP жүйесінде тексерілген. Active Directory жүйесінде алдымен бір есептік жазба үшін кіруді қосуды ұсынамыз.

Пошта

Жүйе хабарламаларды сіздің пошта серверіңіз арқылы жібереді. Бөлек пошта жәшігіне түскен хаттардан өтініштер автоматты түрде жасалуы мүмкін.

Деректерді көшіру

Анықтамалықтар мен есеп деректерін Excel-ден немесе 1С-тен экспортталған файлдан жүктей аласыз. Жүйе әр жолды қолмен енгізгендегідей тексеріп, қателерді импорт журналына жазады.

Жүйенің құрамдастары

Docker контейнерлерінде Frappe Framework, PostgreSQL 18, Valkey және nginx жұмыс істейді. Adapto OS жүйесінің бастапқы кодына қол жеткізе аласыз. Оны өзіңіз өзгерте аласыз немесе кез келген мердігерге тапсыра аласыз. Үшінші тарап компоненттері мен олардың лицензиялары лицензия бетінде келтірілген.
