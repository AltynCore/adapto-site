Установка

Adapto OS ставится на ваш сервер одной командой:

curl -fsSL https://adapto.kz/install.sh | sudo bash

Команда скачивает последнюю сборку, сверяет контрольную сумму и ставит систему в /opt/adapto. Повторный запуск обновляет систему, настройки и данные остаются. Имя сервера можно задать сразу: curl -fsSL https://adapto.kz/install.sh | sudo BOX_HOST=box.center.kz bash.

Сборки с контрольными суммами лежат в открытом репозитории на GitHub. Для сервера без интернета там же есть пакет со всеми программами, включая Docker.

Требования к серверу

Минимум100 пользователей и больше
Процессор2 ядра x86_644 ядра
Память4 ГБ8 ГБ
Диск30 ГБот 50 ГБ, зависит от вложений

Операционная система: Linux x86_64 с iptables или nftables, например Debian 12–13 или Ubuntu 22.04 и новее. Если Docker уже установлен, нужна версия 24 или новее с модулем Compose. В простое Adapto OS занимает около 0,5 ГБ памяти и около 4 ГБ на диске.

Установка без интернета

  1. Скачайте пакет, перенесите на сервер и запустите установку

    Файл adapto-os-<версия>.tar — в релизах на GitHub.

    tar -xf adapto-os-<версия>.tar
cd box-package-<версия>
sudo ./install.sh

    Установщик создаёт файл настроек .env со случайными паролями и выводит пароль администратора на экран. На чистом сервере установка занимает около двух минут.

  2. Укажите адрес сервера

    В файле .env укажите значения: BOX_HOST — имя, которое сотрудники вводят в браузере; BOX_PORT — порт; BOX_URL — полный адрес для ссылок в письмах. Затем повторно выполните sudo ./install.sh. Скрипт применит настройки без удаления данных.

  3. Войдите и добавьте сотрудников

    Войдите как администратор. Создайте учётные записи сотрудников и назначьте им роли или настройте вход через AD/LDAP.

  4. Проверьте установку

    sudo ./check.sh

    Скрипт проверяет службы, место на диске, последнюю ночную копию, планировщик задач и страницу входа. Если он обнаружит проблему, вы увидите сообщение. Результат проверки можно отправить нам вместе с вопросом.

Обслуживание

Обновление

Выпускаем новую версию раз в квартал и поддерживаем две последние. Для обновления используйте новый пакет и команду sudo ./update.sh. Перед обновлением скрипт создаёт резервную копию. Устанавливать обновления не обязательно.

Резервные копии

Система каждую ночь копирует базу и вложения и хранит последние 7 копий. Копии остаются на том же диске. Скрипт backup.sh также сохраняет их в сетевую папку (NFS или SMB), где хранит 14 последних копий.

Восстановление
sudo ./restore.sh backups/<дата>

Подходит и ночная копия. Восстановить можно и на другом сервере — например, если старый вышел из строя.

Вход через AD/LDAP

Сотрудники входят через доменную учётную запись. Система назначает роли по доменным группам. Вход проверен на OpenLDAP. В Active Directory рекомендуем сначала включить его для одной учётной записи.

Почта

Система отправляет уведомления через ваш почтовый сервер. Письма, которые приходят на отдельный ящик, могут автоматически создавать обращения.

Перенос данных

Вы можете загрузить справочники и учётные данные из Excel или выгрузки 1С. Система проверяет каждую строку так же, как при ручном вводе, и записывает ошибки в журнал импорта.

Компоненты системы

Frappe Framework, PostgreSQL 18, Valkey и nginx в Docker-контейнерах. У вас есть доступ к исходному коду Adapto OS. Вы можете менять его самостоятельно или привлекать любого подрядчика. Компоненты третьих лиц и их лицензии перечислены на странице лицензии.
