# nginx на хостинге не должен отдавать .html статикой

Plesk на ps.kz по умолчанию отдаёт `htm` и `html` через nginx, не доходя до Apache, и `.htaccess` для таких запросов не работает: `/science.html` открывался напрямую, без редиректа на `/science`. В «Настройках Apache и nginx» домена `adapto.kz` из списка «Обрабатывать статические файлы с помощью nginx» убраны `htm` и `html` (20.10.2026). Картинки, шрифты и CSS nginx по-прежнему отдаёт сам.

Если на новом хостинге адреса с `.html` снова открываются без редиректа — сначала смотреть этот список.

См. [[site-is-plain-html-in-product-style]].
